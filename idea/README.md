# idea/

이 디렉토리는 작품의 개념, 시각적 방향, 인터랙션 아이디어를 정리하는 기획 문서 공간입니다. 코드 구현 문서라기보다, 프로젝트가 어떤 경험을 만들고자 하는지에 대한 해석 기준을 제공하는 역할을 합니다.

## 포함하는 내용

- 작품의 주제의식과 서사 구조
- 자연, 데이터, AI 해석 사이의 관계에 대한 개념 정리
- 시각적 레퍼런스 이미지와 설치 방향
- 관객 인터랙션 아이디어와 표현 방식

## 함께 참고할 기술 요소

이 폴더는 구현 코드를 직접 다루지 않지만, 아래와 같은 기술적 결정의 방향을 잡는 데 영향을 줍니다.

- Unity `VFX Graph`를 활용한 파티클 기반 표현
- XAI 결과를 색, 밝기, 궤적 분기 등으로 번역하는 시각 언어
- 실시간 인터랙션 장치와 화면 구성을 고려한 장면 설계

## 문서 성격

- `idea.md`: 작품의 핵심 개념과 문제의식
- `implementation.md`: 기술과 연출이 만나는 구현 방향 메모
- 이미지 파일: 분위기와 질감을 공유하기 위한 참고 자료

프로젝트 전체 구조는 [README.md](../README.md)를 참고하세요.
